# QCM SSIAP 3

QCM interactif de préparation SSIAP 3.

## Utilisation

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages dans les réglages du dépôt :

**Settings → Pages → Deploy from a branch → main → / (root) → Save**

Le lien sera ensuite de la forme :

`https://rolln7drktayau.github.io/ssiap3/`

Le QCM fonctionne aussi hors ligne en envoyant simplement `index.html`.
